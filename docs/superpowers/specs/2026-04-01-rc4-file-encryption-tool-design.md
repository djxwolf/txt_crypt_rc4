# RC4 文本文件加密工具 - 设计文档

**日期:** 2026-04-01
**技术栈:** C++ / Qt

---

## 1. 项目概述

开发一个基于 Qt/C++ 的 GUI 工具，用于对文本文件进行 RC4 加密和解密。加密结果格式为 `时间戳@加密字符串`，时间戳同时作为密钥使用，解密时从输出中提取，无需用户额外输入密钥。

---

## 2. 功能需求

### 2.1 核心功能
- **文件加密**: 读取文本文件 → RC4 加密 → 输出 `时间戳@密文`
- **文件解密**: 读取 `时间戳@密文` → 提取时间戳作密钥 → 解密 → 验证 timeout
- **In-place 模式**: 直接覆盖原文件（默认开启）
- **超时验证**: 可配置的 timeout 参数，超期数据视为无效

### 2.2 时间戳密钥机制
- 使用秒级时间戳（如 `1712345678`）作为 RC4 密钥
- 加密时获取当前时间戳，解密时从输出中提取
- 无需用户记忆或输入额外密钥

### 2.3 Timeout 验证
- **默认值**: 600 秒
- **特殊值**: 0 或负值表示不检查 timeout
- **验证逻辑**: `当前时间 - 加密时间戳 > timeout` 则数据无效

## 4. 架构设计

### 4.1 核心组件

| 组件 | 职责 |
|------|------|
| `MainWindow` | 主窗口，布局管理，事件处理 |
| `RC4Cipher` | RC4 加密解密算法实现 |

| `Validator` | Timeout 验证逻辑 |

### 4.2 数据流程

**加密流程:**
```
选择文件 → 读取内容 → 获取时间戳 → RC4加密(时间戳作密钥)
→ 输出 "时间戳@密文" → 写入文件
```

**解密流程:**
```
选择文件 → 读取内容 → 解析"时间戳@密文" → 提取时间戳
→ 验证timeout → RC4解密(时间戳作密钥) → 写入文件
```

## 5. RC4 算法实现

### 5.1 算法步骤

```cpp
// RC4 核心步骤
1. 初始化 S-box (0-255)
2. 用密钥(时间戳字符串) 打乱 S-box (KSA)
3. 生成密钥流并与明文 XOR (PRGA)
```

### 5.2 密钥处理

- 将时间戳转换为字符串作为密钥
- 密钥长度可变，RC4 自动处理

## 6. 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 文件不存在或无法读取 | 弹出错误提示 |
| 解密格式错误（无 @ 分隔符） | 弹出错误提示，说明格式要求 |
| Timeout 验证失败 | 弹出警告，数据已过期 |
| In-place 时文件写入失败 | 弹出错误提示，保留原文件 |

- 示例: `1712345678`
